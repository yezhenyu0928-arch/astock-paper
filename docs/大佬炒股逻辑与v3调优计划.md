## 一、公开资料中的「大佬」炒股逻辑(调研摘要)

### 1. 邱国鹭(高毅资产)——「三好」递进 + 逆向 + 严控回撤
- **选股三要素**: 估值(便宜是硬道理)、品质(定价权/护城河)、时机(人多不去)。
- **三好原则**: 好行业 → 好公司(门槛+成长, 宁要有门槛的低增长, 不要没门槛的高增长)→ 好价格(安全边际)。
- **宁数月亮不数星星**: 只买格局清晰、壁垒深厚、盈利稳定的行业龙头; 舍弃小众题材/劣质小票/高估值赛道。
- **逆向**: 估值够低 + 问题是短期的 + 暴跌不会恶化基本面 → 才逆向加仓("不接下跌的飞刀")。
- **风控**: 2015 熔断"不恐慌割肉、严控回撤、优化持仓"穿越极端行情 —— 强调回撤控制是长期复利前提。
- **映射到本框架因子**: `valuation`/`value_tilt`(估值)、`roe`/`growth`(品质)、`industry`(行业地位/龙头)、`news_guard`(排雷"杀逻辑")。

### 2. 冯柳(高毅资产)——「弱者体系」高仓位单边
- 战略定位: 假设自己在信息/深度/精力/情绪/人脉上都最差 → 只能依靠**时间、赔率、常识**。
- 纪律: **不择时、不对冲、不用杠杆、不做空、始终高仓位单边做多**;"高仓位让情绪波动最小"。
- 选股: 找"高关注度、低购买度"的股票(讨论多但真出手少, 估值易抬升)。
- 风险三分: **杀估值(最好, 跌下来原因即解除) > 杀业绩(其次, 判断是否阶段性) > 杀逻辑(坚决不碰)**。
- **关键启示**: 常态下**维持高权益暴露**(不靠长期低仓位来控回撤), 回撤交给"选股防御性 + 排雷 + 回撤分层降险"处理。
  这正是本项目 @v3 只跑到 ~5-7% 的疑似主因: `regime_downsize` + risk 层可能叠成"双层降仓", 长期欠配拖累收益。

### 3. 国泰海通「红利低波 + 质量突围」(量化选股系列四)
- 流程: 全A剔ST/次新 → 流动性剔除(市值最小20% + 成交额最小20%)→ 低波池(分红约束 + 剔波动率最高20%)
  → 股息率初筛前300 → **低波 + 质量因子等权打分选前100** → 季度调仓(4/8/10/12月底)→ 股息率/低波倾斜加权 + 单票≤5%。
- 质量因子 = ROE + SUE + 加速增长 + 现金流占比。
- 业绩(2013-2026.05): 年化 **20.6%** / 波动 18.7% / 信息比 1.13 / **最大回撤 34.0%** / 月胜率 64%。
  → 纯多头指数级别收益高但**回撤 34% 不满足 <10%**; 说明只靠选股不够, 必须叠加仓位/回撤控制。

### 4. 泓德基金 苏昌景「红利增强」三层框架(实盘达标样本)
- 三层: ①样本池(基本面质地准入 + 尾部风险隔离, 剔除"伪红利")②因子挖掘(量价+基本面+另类, 70-80%功夫在因子端)③组合优化与风险控制(交易成本模型+风险模型+优化器)。
- 实盘(泓德红利优选 2025.04-2026.06): 相对基准超额 **+10.4pct** / **最大回撤 6.64%** / 夏普(年化)**1.35**。
- **关键启示**: 「红利+低波+质量」选股 **叠加 组合优化+风控层** → 可把回撤压到 <7% 同时保持高信息比。
  这就是我们要复刻的模板: 好选股 + 强风控 = 高收益 + 低回撤。

## 二、诊断: 现有 @v3 为何只到 ~5-7% 年化(旧目标 ≥5%/≤5% 下调优的)

1. **常态欠配**: `regime_downsize` 在中性/弱市把持仓数(集中度)压低, 若与 risk 层 `macro_exposure_mult` 叠加,
   易造成长期低仓 → 收益被吃掉(冯柳: 应保持高仓位, 控回撤靠选股+排雷+回撤分层)。
2. **低波过滤偏紧**: 收益型策略(s4/s13)`low_vol_pct` 虽已放宽, 但 s1/s8/s15 仍偏紧, 滤掉了高收益标的。
3. **动量/质量权重仍偏保守**: 研究(国泰海通质量突围 / 邱国鹭品质)与(动量是A股主要超额来源)都支持提高 momentum + roe/growth 权重。
4. **资金档 5万 → 持仓数少**(min_ticket 8000 → 约6只), 分散不足反而放大个股回撤。**已修复: 上调至10万 → 约12-15只**。
