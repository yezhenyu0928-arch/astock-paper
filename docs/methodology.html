因子与风险模型

因子体系总览

本项目参考 MSCI Barra 中国A股模型（CNE5/CNE6）与 Axioma Robust Risk Model， 按免费数据现实裁剪，实现 10 个风格因子。每个因子由 1-3 个描述符加权复合。 当前赛马阵容共 6 只纯个股策略（s26/s27/s29/s32/s37/s42），全部在主板硬约束下运行 （引擎层 main_board_universe 强制过滤：主板前缀+非ST/停牌/北交所/科创创业+上市≥2年+市值≥80亿+日均成交≥8000万）， 回测与实盘同源、口径一致。各策略因子权重见下方"各策略详解"。 此外另有 3 只全A股候选策略（s53/s54/s55，覆盖主板+科创688+创业300·301+北交）正在回测验证，达标后入赛马，见页底"全A股候选策略（测试中）"。

数据处理管线

  1. 去极值（MAD Winsorize）：对每个因子截面，用中位数绝对偏差（MAD）设定上下界， 越界值截断到边界。公式：bound = median(x) +/- 5 x 1.4826 x MAD(x)。防止个别的极端数值扭曲整体评估。
  2. 标准化（Z-score）：z = (x - mu_w) / sigma_eq，其中 mu_w 为市值加权均值，sigma_eq 为等权标准差。 处理后，因子分布以市值加权组合为中心(暴露约=0)，等权标准差约=1。
  3. 正交化（Gram-Schmidt）：按固定顺序(BETA→SIZE→VALUE→...→EARNINGS_YIELD)依次对前一因子做WLS回归取残差。 消除因子间的共线性——例如残差波动与Beta天然相关，正交化后残差波动不再包含Beta已解释的部分。
  4. 缺失处理：缺失的描述符在复合时按可得权重重归一，标准化后NaN填0（池中性）。

风险模型（Barra 横截面法）

结构模型：r = Xf + u（个股收益 = 因子暴露 x 因子收益 + 特异收益）。

  1. 暴露矩阵 X：N只股票 x 6个风险因子(size, beta, momentum, resvol, liquidity, btop)的当天暴露值。
  2. 因子收益估计：对每个交易日，用t-1日暴露对t日个股收益做WLS（权=sqrt(市值)）横截面回归，得因子收益 f_t。
  3. 因子协方差 F：f_t 的EWMA协方差（半衰期90日），x252年化。
  4. 特异波动 σ_i：残差 u_i 的EWMA标准差（半衰期42日），xsqrt(252)年化。
  5. 组合预测波动：σ_p = sqrt( h'X F X'h + Σ h_i^2 σ_i^2 )，h=各持仓市值权重。
  6. 组合暴露：X_p = Σ h_i · z_i。因标准化以市值加权均值为中心，X_p 本身即为主动暴露（相对于市值加权基准）。

对称性说明（暴露怎么看）

暴露值为正 → 组合在该因子上比市值加权基准偏多（如正Beta = 比市场Beta更高）。
暴露值为负 → 组合在该因子上比基准偏少。
暴露值在[-0.5, 0.5] → 基本中性，无明显偏离。
暴露值>|1| → 显著偏离，需要注意该维度的集中风险。

投资纪律：单策略回撤 ≤ 年化（铁律）

用户设定：单策略最大回撤不得超过其年化收益率。风控层 risk.py 对每只策略设 max_dd 上限，并配合跟踪止损（stop_pct）与大盘冻结硬熔断（market_freeze）实现。 当前 6 只策略均满足该约束，例如 s42（回撤14.6% ≤ 年化16.6%）、s27（回撤8.9% ≤ 11.1%）。任何回测违反此律的变体（如 s44/45/46 集中度变体、回撤>年化）一律淘汰、不在看板展示。

与 Barra CNE6 / Axioma 的差异声明

  • Beta：使用60日窗口(vs CNE6的504日/252日)，因本项目数据覆盖较短(2018年起)，声明短窗差异。
  • 动量(RSTR)：不做CNE6的11日滞后平均处理，直接使用252日剔除最近21日的指数衰减累积超额收益。
  • 残差波动：无CMRA(月累计收益范围)描述符，仅用日收益标准差DASTD与ATR近似。
  • 流动性：仅有STOM(月换手率对数)，无STOQ(季度)/STOA(年度)三个档位。
  • 质量：无季频ATO(资产周转率)/GPM(毛利率)数据，仅用年报ROE加杠杆代理。
  • 成长：仅净利润增长率，无营收增长率数据。
  • 杠杆：无资产负债表数据，用1-1/PB近似资产负债率，属于粗粒度代理。

免费数据局限

  • 无分析师预期数据：无法构建Analyst Sentiment、预期EP、预期股息因子；国信《超预期精选组合》"研报标题超预期+分析师上调净利润"事件池在回测中由 event_pool（近期盈余公告且SUE>0）代理，真实文本信号待实盘接 news_engine 验证（故 s52 仅作观察级）。
  • SUE 覆盖受限：标准化预期外盈利依赖 profit_q 表，当前仅覆盖约376只主板，对纯小盘策略实际选股贡献有限（s42 已计入但权重仅0.10）。
  • 无季频资产负债表与现金流：无法严格构建Leverage、Investment Quality、Earnings Quality因子。
  • 无真实流通股本：换手率为amount x 100 / market_cap反推近似，市值加权也只能用总市值而非流通市值。
  • 市场代理为sh510300 ETF：库内无sh000300指数日线，用沪深300ETF后复权收益替代。
  • 无真实宏观数据：宏观因子(利率变化、PMI意外)在本模型中占位为0；已通过 macro.py detect_regime() 用PE分位+MA方向做regime自适应补偿。

宏观 Regime 检测

macro.py detect_regime()：基于沪深300 PE十年分位 + MA20/MA60均线方向判断市场状态，用于风控层的大盘冻结硬熔断（market_freeze）——大跌日全策略统一触发、暂停开仓，属安全网而非选股信号。

  • 扩张(expansion)：PE分位≤50% 且 MA20>MA60（估值合理+趋势向上）→ 正常开仓。
  • 收缩(contraction)：PE分位>70% 或 MA2050%（高估或下行）→ 触发大盘冻结防御，降低新开仓。
  • 中性(neutral)：其余情况 → 使用默认因子权重。

注：当前 6 只参赛策略均设 regime_downsize: false（不启用"弱势减仓"软防御），避免重蹈 s43 因防御过度被压到11%的覆辙；集中防御仅保留 risk 层大盘冻结硬熔断。

行业动量倾斜

macro.py industry_momentum()：计算申万31行业近60日等权涨幅排名。该信号曾用于早期策略的行业景气度倾斜；当前 6 只策略以个股多因子排名为主，行业动量作为 mf_core 的 ind_mom 候选因子接入（s50 行业动量轮动实测未达阈值，作观察级）。
