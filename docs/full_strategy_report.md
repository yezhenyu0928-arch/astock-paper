### 核心算法（伪代码）

```
for each 交易日 sd:
    计算NAV = (cash + 持仓市值) / 100000
    
    if 是每周最后交易日:
        for each ETF in pool:
            dates = 该ETF所有<=sd的交易日
            if len(dates) < 11: continue
            p0 = dates[-1]的复权收盘价  (当日)
            pn = dates[-11]的复权收盘价 (10日前)
            动量 = p0 / pn - 1
        
        取动量最高的ETF（动量>0才入选）
        
        if 需要换仓:
            卖出旧持仓
                amt = 股数 × 复权价
                fee = max(amt × 0.00025, 5) + amt × 0.0005
                cash += amt - fee
            
            买入新ETF
                trade_amt = cash × 0.98
                shares = floor(trade_amt / 复权价 / 100) × 100
                amt = shares × 复权价
                fee = max(amt × 0.00025, 5)
                cash -= amt + fee
```

### 选股评分算法（Python）

```python
def s1(code, date):
    r = conn.execute("SELECT close, adj_factor FROM daily_bar WHERE code=? AND trade_date=?", (code, str(date)))
    if not r: return None
    px = float(r[0]) * float(r[1] or 1.0)
    if not px: return None
    
    r2 = conn.execute("SELECT market_cap FROM fundamental WHERE code=? AND trade_date<=? ORDER BY trade_date DESC LIMIT 1", (code, str(date)))
    if not r2 or not r2[0]: return None
    mc = float(r2[0])
    if mc <= 0: return None
    
    xs = conn.execute("SELECT close, adj_factor FROM daily_bar WHERE code=? AND trade_date<=? ORDER BY trade_date DESC LIMIT 65", (code, str(date)))
    if len(xs) < 60: return None
    
    mom = 复权价(xs[0]) / 复权价(xs[59]) - 1  # 60日动量
    if mom < -0.3: return None  # 过滤深跌
    
    return -mc * (0.7 + max(0, mom) * 0.3)  # 越小越好
```

## 5. 费用计算说明

所有回测严格按照以下费用模型：

### 买入费用

```
commission = max(成交金额 × 0.00025, 5)
总费用 = commission
（ETF免印花税，个股卖出才收印花税）
```

### 卖出费用

```
commission = max(成交金额 × 0.00025, 5)
stamp_tax = 成交金额 × 0.0005
总费用 = commission + stamp_tax
```

### 成交规则

- 成交价 = 调仓日复权收盘价
- 股数 = floor(可用资金 × 目标权重 / 成交价 / 100) × 100（100股整手）
- 买入时可用资金 = cash × 0.98（留2%现金缓冲）
- 个股买入每只权重 = cash × (1/5) × 0.95
